# Desktop v0.1.94

修复海外 IQ 通过本机代理获取播放内容时返回空内容的问题。请配套更新网关 **v3.9.124**，以获得详情兜底、源站短暂空响应重试及重启后会话保留修复。

## 修改

- 对 `https://cache-video.iq.com/dash` 使用经现有 HTTP/HTTPS 代理 CONNECT 的 HTTP/2 传输，保留签名路径、查询参数和认证请求头。
- 保留 TLS 证书验证，支持压缩响应、取消和响应体大小限制；代理拒绝或连接失败时不回落直连。
- 其他认证请求沿用现有传输。国内 `iqcn` 不属于本次修改范围。

## 验证

- 8 个 Node 传输测试与 32 个相关 Bun 回归通过，覆盖签名参数保留、CONNECT、压缩响应、代理拒绝、取消和提前断连。
- 主进程及渲染进程类型检查通过。
- 实际客户端粘贴第四集链接，详情正常列出四集，并完整下载 3840×2160 HEVC、日语杜比 5.1 + AAC 双音轨成品。全片音视频解封装和开头/中间/结尾解码抽检通过。

测试中的本地证书是公开测试夹具，不包含用户会话或生产凭据。终端 TUI 版本不变，本次客户端修复位于 Electron 主进程。
