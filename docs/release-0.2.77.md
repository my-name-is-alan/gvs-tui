# TUI v0.2.77

修优酷「合并报错：下载的文件中没有音频轨道」。

## 原因

报错原文来自音轨校验（`ffmpeg.ts`）：

> 音轨校验失败：下载的文件中没有音频轨道，未生成成品；分轨视频需要同时取得独立音轨

也就是说**下载下来的文件里确实没有音轨**。两条路径会走到这里：

1. `audio_delivery=muxed`（酷喵 TV / App 档）：客户端信任视频 m3u8 自带音轨；
   若源站把音轨拆走，视频就是无声的，一路下载到校验才炸；
2. `audio_delivery=separate`（帧享 HQ）：所选音轨的播放列表 URL 缺失时会被 soft-skip，
   如果**所有**选中音轨都被跳过，同样没有音轨被封装。

## 修法

- 视频下载完先**探测实际轨道**（MP4Box）：muxed 档没有音频时，自动改用源站返回的默认独立音轨；
- separate 档所有选中音轨都被跳过时，退回默认音轨；
- 两条路都拿不到音轨时，**在封装前**用明确文案停下（不再拖到校验阶段报"没有音频轨道"）；
- 探测失败（容器非 MP4 等）保持原行为，不误判。

## 验证

- 优酷相关用例 37 项通过（含 audio_delivery 判定、TS 解密、会员链路）；
- `tsc --noEmit` 干净，desktop 共用同一份代码。
