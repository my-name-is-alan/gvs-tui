# GVS RE 0.6.0-gvs-iq.6

修复腾讯《多喜一家人》第 4 集的解密后花屏：新增 `CHACHA20_V3_SDD`，在外层 V3 后处理独立的 HEVC SDD/V2 稀疏加密。恢复后的字节已经包含原始 HEVC 转义，避免再次转义造成无报错的局部画面损坏。

保留音频包、PES 时间戳和 PCR；跨 TS/PES 的 NAL 统一重组处理。将已解密视频的 PMT 私有类型改为标准 HEVC 并重算 CRC，避免 MKV 封装器遗漏视频轨。单独音频仅解外层，未知容器或参数明确失败。原 CHACHA20、CHACHA20_V3 和 IQ 行为保持兼容。

真实两个加密分片经维护版 RE 解密，单片、拼接后的约 18 秒及最终 MKV 均通过 FFmpeg 视频与音频严格解码，3840×2160/60fps，抽帧正常。验证限于这些分片，未宣称整集逐帧验收。原生 V2 对照向量、跨 PES、转义、时间戳/PCR、音频、PMT/CRC 与 IQ 共 37 项回归通过。
